# Khmer text review

Every Khmer string in Khleng Ek beside its English, for a native speaker to check. The strings live in
`i18n/locales/km.json`; settings and install prompts are shared with the other games and reviewed there.

Worth a second look: ខ្លែងឯក (the kite) and ឯក (its humming bow), សត្វកុក for the egrets, ខ្សែទង់ for the
festival bunting, គោមហោះ for sky lanterns, ខ្យល់ខ្លាំង for the "Gust" power-up, រោងជាង for the workshop,
កម្លាំងខ្សែ for line strength, and how natural the story lines between Dara and Grandpa Sok (លោកតាសុខ) sound.
